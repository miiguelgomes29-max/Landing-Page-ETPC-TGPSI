Sobre o TGPSI

O curso de TGPSI é uma formação profissional de nível 4 que te prepara para os desafios do mercado digital. Durante 3 anos, vais adquirir dupla certificação (12.º ano + Certificado Profissional) num ambiente altamente prático.

Com forte ligação às empresas da região, terás a oportunidade de realizar a Formação em Contexto de Trabalho (Estágio) aplicando os teus conhecimentos em cenários reais.

O que vais aprender?

Programação

Desenvolve aplicações desktop e lógicas de programação utilizando linguagens modernas como C/C++, C# ou Java.

Web Design & Dev

Cria websites dinâmicos e landing pages (como esta!) utilizando HTML, CSS, JavaScript e PHP.

Bases de Dados

Modela e gere grandes quantidades de informação utilizando sistemas como SQL Server ou MySQL.

Redes Informáticas

Instala, configura e gere equipamentos de rede, garantindo a comunicação e a segurança dos sistemas.
